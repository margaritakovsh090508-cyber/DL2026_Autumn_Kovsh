# Часть 1. Проектирование и анализ

**Проект:** Погода с настроением (мемы под прогноз)
**Стек:** React + Vite (frontend), FastAPI + SQLite (backend), OpenWeatherMap API

---

## 1.1. Пользовательские сценарии

**Сценарий 1. Просмотр погоды с мемом**

> Как пользователь, я хочу ввести название города и увидеть текущую погоду
> вместе с забавным мемом, соответствующим погодным условиям, чтобы поднять
> себе настроение.

**Сценарий 2. Прогноз на несколько дней**

> Как пользователь, я хочу увидеть прогноз погоды на 5 дней вперёд,
> и для каждого дня получить свой мем, чтобы планировать настроение
> на неделю.

**Сценарий 3. Поделиться открыткой**

> Как пользователь, я хочу поделиться «открыткой» (погода + мем) с друзьями
> в соцсетях или мессенджерах, чтобы рассмешить их и показать, какая погода
> у меня за окном.

**Сценарий 4. Добавить свой мем**

> Как пользователь, я хочу добавить свой мем в базу, привязав его
> к определённому типу погоды, чтобы другие пользователи могли видеть
> мой контент и оценивать его.

---

## 1.2. Функциональные требования

### Обязательные (MVP)

**Frontend:**

- Поле ввода названия города.
- Отображение текущей погоды: температура, описание, иконка.
- Отображение мема, соответствующего погоде.
- Прогноз на 5 дней с мемом на каждый день.
- Переключатель режима «Сейчас / 5 дней».
- Кнопка «Поделиться» (Web Share API + fallback в буфер обмена).
- Кнопка «Лайк» на меме.
- Форма добавления нового мема.
- Адаптивный минималистичный дизайн.

**Backend:**

- Получение текущей погоды по названию города через OpenWeatherMap.
- Получение прогноза на 5 дней.
- Хранение мемов в БД, сгруппированных по категориям погоды.
- Выдача случайного мема по категории.
- Обработка ошибок (город не найден, API недоступен, неверная категория).
- Эндпоинты для добавления мема и лайка.

### Опциональные (реализованы частично)

- ✅ Прогноз на 5 дней с мемами.
- ✅ Лайки мемов.
- ✅ Локальные SVG-иллюстрации.
- ❌ Определение геолокации пользователя.
- ❌ Локализация RU/EN.
- ❌ Выбор мема из нескольких предложенных.

## 1.3. Проектирование API

Базовый URL: `http://localhost:8000/api`

| Метод | Путь | Параметры | Ответ |
|-------|------|-----------|-------|
| GET | `/weather` | `city` (string, обязательный) | `{ city, temp, description, icon, category, meme }` |
| GET | `/forecast` | `city` (string, обязательный) | `{ city, days: [{ date, temp, description, icon, category, meme }] }` |
| GET | `/memes` | `category` (опц.) | `[Meme]` |
| GET | `/memes/random` | `category` (обязательный) | `Meme` |
| POST | `/memes` | `{ url, text, category }` | `Meme` (201) |
| POST | `/memes/{id}/like` | — | `Meme` |
| GET | `/categories` | — | `["hot","cold","rain","snow","wind"]` |
